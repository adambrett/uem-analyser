# UEM Microstructure Fixtures

Use the files in `valid/` to exercise the browser upload flow.

- Select `Ada session 1.txt` by itself to get a single `.xlsx` download.
- Select both Ada files to get one workbook with two worksheets.
- Select the Ada and Grace files together to get a `.zip` download with one workbook per participant.
- Select `StandaloneExample.txt` to exercise the warning for filenames without `session`.

The files in `invalid/` are for parser error checks. Do not include them in a normal valid upload batch.
